## CarStore

**Em desenvolvimento**

Aplicação web desenvolvida na disciplina de PI, utilizando Java, Servlets e banco de dados H2.
O projeto tem como foco o desenvolvimento back-end com Java, processamento de requisições HTTP, acesso ao banco de dados com JDBC e organização do código utilizando o padrão DAO.

### Tecnologias

Java • Servlets • JDBC • JSP/JSTL • H2 Database • Maven • Apache Tomcat • HTML

### Funcionalidades e Conceitos abordados

- Cadastro de veículos
- Consulta e listagem de veículos cadastrados
- Armazenamento de dados no banco H2
- Processamento de requisições GET e POST

- Desenvolvimento de aplicações web com Java
- Servlets e mapeamento de URLs
- Métodos HTTP e comunicação entre páginas e back-end
- Conexão e consultas SQL utilizando JDBC
- Separação de responsabilidades com Model, DAO e Servlet
- Renderização de dados com JSP/JSTL
